# Arseille

Arseille is a customized vending machine enhanced with real-time image processing.

Its core operation resembles that of a conventional vending machine; however, the selection of beverages presented is dynamically filtered based on predefined criteria. Specifically, the system utilizes user age (extracted via image analysis) and real-time weather data to determine the set of available options.

> [!NOTE]
> This project runs entirely in the browser and is intended for local use only.
