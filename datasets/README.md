# Datasets

This is a sample directory structure of the datasets used in training the models.

```
datasets/
├── age_estimation/
│   └── UTKFace/
│       └── *.jpg
└── face_detection/
    └── OpenImagesV7/
        ├── images/
        │   ├── train/
        │   │   └── *.jpg
        │   └── val/
        │       └── *.jpg
        └── labels/
            ├── train/
            │   └── *.txt
            └── val/
                └── *.txt
```
